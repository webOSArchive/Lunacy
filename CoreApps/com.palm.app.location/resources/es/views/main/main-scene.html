Servicios de ubicación
Para sitios Web
Borrar mis datos de ubicación
Tu ubicación nunca se proporcionará a los sitios web que la soliciten.
Se te pedirá autorización cuando un sitio web solicite tu ubicación.
Para aplicaciones
Se proporcionará automáticamente tu ubicación a las aplicaciones que la soliciten.
Se te pedirá autorización cuando una aplicación solicite tu ubicación.
Marcar fotos con Geotags
Almacena las coordenadas de GPS de tu ubicación cuando usas la cámara.
Recopilación de datos en segundo plano
Permite que Google recopile automáticamente datos de ubicación anónimos para mejorar la calidad de los servicios de ubicación.
