Service de position
Pour les sites Web
Effacer mes données de positionnement
Votre positionnement ne sera jamais fourni automatiquement aux sites Web qui le demandent.
Vous devrez donner votre autorisation chaque fois qu’un site Web désirera connaître votre positionnement.
Pour les applications
Votre positionnement sera automatiquement fourni aux applications qui le demandent.
Vous devrez donner votre autorisation chaque fois qu’une application désirera connaître votre positionnement.
Photos Geotag
Stocke les coordonnées GPS de votre positionnement lorsque vous utilisez l’appareil photo.
Récupération des données contextuelles
Permet à Google de recueillir automatiquement les données de positionnement anonymes afin d’améliorer la qualité des services de positionnement.
